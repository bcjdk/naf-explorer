# Deferred work

- **Workflow card at the start of a beat.** The workflow card's current step and its "waiting for …" line change at the start of a beat, before the answering signal is drawn (for example "waiting for Intent: desired state ready" disappears at the start of P5). Only a completed workflow's steps wait for their marker. A disappearing line cannot fade out without keeping the old state on screen; fix if it reads as out of order.
